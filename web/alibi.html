    How to read the verdict

    Each outcome is an assertion about the supplied evidence artifact. None certifies that the coding agent fixed a vulnerability or implemented correct behavior.

    01

    Exact commit binding

    A green run on SHA A cannot stand in for a claim made about SHA B. The Git graph decides whether the cited result is ancestral.

    02

    Provider-reported only

    GitHub run links identify provider records; the local Kiro case has no public transcript URL. Both recorded snapshots and editable local logs lack signed independent attestation.

    03

    No synthetic failure

    Three examples use real workflow records with hypothetical claims. The fourth draws from an authentic Kiro session; no post-edit rerun was seen in that saved session. Outside evidence remains unknown.
