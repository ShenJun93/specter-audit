    How to read the verdict

    Each outcome is an assertion about the supplied evidence artifact. None certifies that the coding agent fixed a vulnerability or implemented correct behavior.

    01

    Exact commit binding

    A green run on SHA A cannot stand in for a claim made about SHA B. The Git graph decides whether the cited result is ancestral.

    02

    Provider-reported only

    Run IDs and source URLs point to real GitHub Actions pages. Snapshots are dated and are not cryptographically signed attestations.

    03

    No synthetic failure

    The examples use real successful workflow records and explicit hypothetical claims. The empty dossier does not assert actual CI was absent.
